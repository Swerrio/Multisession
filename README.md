# Multisession

Stay connected to several servers and singleplayer worlds from one game window, and switch
between them in a second.

## How it works

Open the pause menu and press **Sessions**. Start a new session on another server or world, and
the one you were in keeps running in the background: it stays connected, keeps receiving chat,
time and damage, and you come back to it exactly where you left. A singleplayer world is paused
while it is in the background.

Press **F6** to jump to the next session.

## Features

* Several servers and worlds open at once, each with its own chat, HUD, toasts and server
  resource pack
* A warp jump effect with its own sound when you switch, which you can turn off
* Each session can use its own account, for players with In-Game Account Switcher
* Quick join for pinned servers, and joining by address straight into a new session
* Versions of one server resource pack are loaded together, so switching between the servers
  that send them does not reload resources
* Server addresses can be hidden for streaming

## Requirements

* Minecraft with Fabric Loader and Fabric API
* Client side only: nothing is needed on the server
